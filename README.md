# ScooterRental
ScooterRental —  WPF-приложение для учёта аренды электросамокатов, пользователей и платежей. Проект разработан в рамках учебной практики УП.01.01 и курсового проекта по дисциплине «Технология разработки и защиты баз данных».

## Основной функционал
- Регистрация и авторизация пользователей.
- Разграничение доступа по ролям: пользователь и администратор.
- Хэширование паролей.
- Работа с пользователями, поездками, транспортом, тарифами и подписками.
- Просмотр поездок и построение диаграмм по их суммам.
- Стилизация интерфейса и переключение темы.
- Дополнительные функции (капча, смена пароля, поиск, фильтрация и экспорт отчётов)


## Пользовательский интерфейс
Приложение разработано с использованием WPF и XAML. Интерфейс состоит из страниц с навигацией и использует словари стилей для оформления элементов управления. Предусмотрена смена цветовой темы.

## Используемые технологии

| Технология | Назначение |
|---|---|
| C# | Реализация бизнес-логики приложения |
| WPF | Разработка графического интерфейса |
| XAML | Описание страниц, элементов управления и стилей |
| Microsoft SQL Server | Хранение и обработка данных |
| Entity Framework | Доступ к данным и взаимодействие с базой данных |
| Visual Studio | Разработка и отладка приложения |
| Microsoft Excel / Word | Формирование отчётов об инвентаризации |

## Структура базы данных
Сущности бд:
- User — пользователи и их данные
- Roles — роли пользователей
- Subscription — подписки и скидки
- Rentals — поездки, даты, сумма и статус оплаты
- Vechicles — транспортные средства
- Tariffs — тарифы аренды
- Status — статусы оплаты
- Review — отзывы о поездке
- Parking — адреса парковок транспорта
- Maintenance — данные о поломках
- TypeOfMaintenance — типы поломок транспорта
- Vechicles_Models — модели транспорта
- Vechicles_Types — типы транспорта
  
Поездки связаны с пользователями, транспортными средствами, тарифами и статусами оплаты.
